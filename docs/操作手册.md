# LangStudy 操作手册

网站：https://lang.aidigitcloud.cn

用浏览器打开。电脑和手机都可以。麦克风要在 HTTPS 页面里才允许使用，请用上面的地址，不要用没上锁的链接。

第一次打开、数据库里还没有人时，页面会让你创建账号。这个账号就是管理员。之后的人要用邀请码注册。

## 登录和注册

- 已有账号：打开网站，选「登录」，填写用户名和密码。登录状态保留 30 天。
- 新用户：向管理员要邀请码，或打开管理员发来的注册链接（地址里带 `?invite=`，邀请码已经填好）。选「用邀请码注册」。
- 忘记密码：自己改不了，请管理员在「用户与邀请 → 用户」里重置。临时密码只显示一次。
- 同一账号 15 分钟内密码连续错 5 次，会锁 5 分钟。

右上角可以切换浅色、深色或跟随系统。退出在「账号设置」。

左侧（手机上是菜单）有这些入口：

| 入口 | 谁能看见 | 做什么 |
|---|---|---|
| 首页 | 所有人 | 出题、上传课件、接着做没完成的练习 |
| 复习 | 所有人 | 生词本、错句本，按遗忘曲线复习 |
| 口音听辨 | 所有人 | 听一句英语，猜是哪里的口音 |
| 练习历史 | 所有人 | 回看自己的练习和报告。管理员可勾选看所有人 |
| 学习笔记 | 所有人 | 已保存的单词、语法、句型 |
| 用户与邀请 | 仅管理员 | 邀请码、用户、用量、导入话题 |
| 账号设置 | 所有人 | 主题、改密码、退出 |

## 开始一次练习

首页标题是「今天练什么话题？」。

1. 选学习语言：English 或 日本語。
2. 选难度：入门、中级、高级。有过练习后，页面会根据最近成绩建议升降；可以打开「按最近成绩自动调节难度」。
3. 选题量：话题问答可以选 3、5、8 题。短文和情景对话的长度随难度定。自由对话不限轮数。
4. 选听力口音。英语可以选美国、英国、澳大利亚等；标了「模拟」的是用该国音色读英文。日语可选默认或东京标准音。这个选择会记住。
5. 选练习形式，在搜索框写下话题（也可以点下面的例子），再点「生成练习」。

同一话题、同一难度、同一形式再练时，会问你「用上次的题」还是「换一套新题」。用上次的题不再调用模型，学习笔记也会带过来。

生成中途不要关页面。好了会自动进入练习。首页「继续上次的练习」默认打开最近一次没做完的；右边下拉可以选择近一周内已导入、未开始或以前生成过的话题。没做完的点进去接着做，已经评过分的会用同一套题再开一份新练习。每答一题都会自动保存，刷新或关掉页面也不会丢。

如果最近某一项分数明显偏低，首页会显示「薄弱项」，可以点「专项练一组」。听力弱会出精听，发音弱会出跟读，流利度弱会出需要连续说的问题。

页面上如果出现「演示模式」，说明还没接上大模型，内容是内置示例。

## 五种练习

练习页上方可以在「练习」和「学习笔记」之间切换。右侧（手机上在设置里）是语速、音色和结束按钮。

**话题问答。** 问题会朗读。你可以「说」或「写」。打开「AI 追问」后，答完会根据你的话再问一句，可以跳过。

**情景对话。** 先选自己演的角色。对方台词自动朗读，轮到你时开口。两种说法：「照着说」对着原文练发音；「自由说」只给中文意思，自己组织句子。对话里的男女声跟角色走，不跟下面的音色设置走。

**短文。** 可以听全文或逐句听，再逐句跟读。跟读后能看到没读准的词。理解题在后面。「影子跟读」是原音播放时一起说（建议戴耳机），结束后会显示你比原音晚几秒开口、用时是原音的几倍。影子跟读整段连续播放，中间不切开。

**精听填空。** 听录音，把每句挖掉的一两个词填上。这一项只算听力。

**自由对话。** 没有固定剧本。AI 扮演同事、面试官、店员等，根据你说的往下聊。点「结束对话」后进入评分。自由对话里 AI 用男声。

作答时点麦克风开始录音，识别文字会显示出来，可以回放、重录。浏览器不支持语音识别时，用「写」。

点「结束并评分」后稍等，会打开报告。同一份练习重复点，不会评两次。

## 练习时可以改的设置

| 设置 | 作用 |
|---|---|
| 语速 | 0.8×、1×、1.2× |
| 音色 | 女声或男声，默认女声。只影响单人朗读（问题、短文、精听、笔记、复习）。情景对话和自由对话的角色声不变 |
| 听力口音 | 选具体口音后，这一句改用对应地区的声音。选「默认音色」用站点配置的朗读声音 |
| 盲听 | 先藏起原文，只听录音。需要时再点开 |
| 显示中文翻译 | 在原文下显示中文。第一次打开才会翻译这一句，之后会记住 |
| 免手动 | 话题问答、情景对话、自由对话可用。对方说完自动开麦，你停顿约 1.5 秒自动提交 |

句子旁边的「译」只翻译这一句。「评测发音」只有在你点了之后才评，跟读和照着说之后会出现。

## 报告、笔记和复习

报告给出综合分和六项：听力理解、发音清晰度、口语流利度、语法准确性、词汇运用、内容与表达。全部用文字作答时，发音和流利度显示未评估，不计入综合分。

每条作答可以在「我的录音」和标准音之间对比。被改正的句子会进入错句本。值得记下的单词和句型，点星号收藏进生词本。

报告页可以「分享报告」，生成一个不用登录就能看的链接，里面包含你的录音。不需要时关闭分享，链接立刻失效。报告页也可以「同话题再练一次」。

学习笔记包括单词（读音、词性、释义、例句）、语法（讲解、易错、例句）和句型。练习页切到「学习笔记」，或在报告底部生成。生成后自动保存，可以「重新生成」换一份。左侧「学习笔记」能回到以前的笔记。例句可以按当前口音播放。

「复习」按遗忘曲线安排。今天该复习的张数会显示在入口上。单词交替「听音回忆」和「看中文说出来」；错句要开口说出正确句子。四档是「忘了 / 模糊 / 记得 / 很熟」，决定下次什么时候再出现。点「评测发音」才给发音打分。

## 口音听辨

左侧「口音听辨」。听一句英语，从四个选项里猜口音，一轮 10 题。可以打开「包含模拟口音」（日本、德国、法国、拉美）。答完可以把这几种口音对比着听。

## 用课件出练习

首页点「上传资料」，两条路合在同一个窗口里。

**整理成课程包（所有人）。** 选择 PDF、PPTX 或 Word，也可以把讲义文字粘贴进去，再点「整理成课程包」。文字在服务器本地提取，模型只做归类，不改写原文。整理好会进入课程包：按课件里实际有的内容列出话题问答、情景对话、精听、听后回答、口语题、自由对话和学习笔记。可以「从第一项开始」，也可以只点某一项。笔记已经按原文整理好。

**导入话题（仅管理员）。** 管理员打开同一窗口时，还能选 `.md` 或 `.zip`。先展开「发给其他模型的说明」，点「复制说明」，把说明和课件（或话题、目标语言）发给别的大模型。模型交回 Markdown 后，在首页「上传资料」里选这个文件，点「导入话题」。一个文件里可以有多个话题，也可以把同一话题的不同级别、不同形式都写进去；每一个从 `# 话题名` 开头的块导入后都是一份独立练习，会一起导入。导入后的练习记在管理员自己的账号上，出现在历史记录和学习笔记里。学习笔记里的单词、语法、句型会全部保留。导入失败时，窗口里会写出哪一块格式不对，同一文件里其余能导入的仍会进去。

格式以窗口里的说明为准。常用字段是：语言（`en` / `ja`）、级别（`beginner` / `intermediate` / `advanced`）、形式（`questions` 话题问答、`dialogue` 情景对话、`article` 短文、`dictation` 精听填空、`chat` 自由对话）。

## 管理员

「用户与邀请」有三个标签。导入话题已并进首页「上传资料」。

**邀请码。** 可注册人数 1 到 100，有效期 1、7、30、90 天或不过期，备注用来记住发给谁。生成后可以复制邀请码，或复制注册链接。列表里能看到谁用过、用了几次，可以作废。

**用户。** 看每个人的练习次数和最近练习时间。停用后对方马上退出，不能再登录；可以再启用。重置密码会给出一个临时密码，只显示一次。

**用量与统计。** 看每人今天和近 30 天调用了多少次模型、语音和朗读，以及积分（以网关返回的为准）。下面有「大家最常犯的问题」。

练习历史里，管理员可以打开「显示所有用户的记录」，点进任何人的报告。

## 账号

「账号设置」里改主题、改密码、退出。新密码至少 8 位。改完需要重新登录。

## 遇到这些情况

- 点了播放要等一下才出声：第一句合成完就会响，后面的句子在播放时提前准备。已经听过的句子会马上重播。
- 问号或句号后面应有短暂停顿；句子中间不该有一顿一顿的空白。若刚更新过，先刷新再听。
- 麦克风没反应：确认用的是 https://lang.aidigitcloud.cn ，并且浏览器允许了麦克风。微信里如果被拦住，用系统浏览器打开同一地址。
- 识别不出字：练习页改用「写」，或换一个支持语音识别的浏览器。
- 生成或评分一直转：看页面上的错误提示。网络中断时，已答的题仍在，回到「继续上次的练习」即可。
