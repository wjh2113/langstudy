# LangStudy 听说练习

输入一个话题，生成短文、情景对话或一组问题（比如面试题）。材料可以朗读播放，你用语音（或文字）作答，结束后从六个维度打分。第一阶段支持英语和日语，PC 优先，界面已适配手机宽度。

## 快速开始（macOS）

需要 Python 3.10+ 和 Node.js 18+。

```bash
cd langstudy
chmod +x start.sh
./start.sh
```

第一次运行会自动安装依赖。然后用浏览器打开 http://localhost:5173 。

### 第一次打开：创建管理员

数据库里还没有用户时，页面会让你创建账号，**这个账号就是管理员**。管理员能用所有练习功能，另外多一个“用户与邀请”页面：

- **生成邀请码**：可设定能注册几个人（1–30）、有效期（1 / 7 / 30 天或不过期）、备注给谁的。生成后可以复制邀请码，或直接复制注册链接（`http://你的地址/?invite=XXXX-XXXX`），对方打开链接就是注册页，邀请码已填好
- **管理邀请码**：查看谁用了哪个码、已用几次，随时作废
- **管理用户**：看每个人的练习次数和最近练习时间；停用 / 启用账号（停用后立即下线）；重置密码（生成一个临时密码，只显示一次）
- **历史记录**里可以勾选“显示所有用户的记录”，打开任何人的报告

普通用户只能看到自己的练习记录。每个人都可以在“账号”页修改密码、退出登录。登录状态保存 30 天。

### 接入 AIapiMgr 网关

`backend/.env` 里已经填好了网关地址、租户 `langstudy` 和 API Key（这个文件不会提交到 git）。接入后：

| 功能 | 网关能力 |
|---|---|
| 生成材料、评分 | `quality-chat` |
| AI 追问 | `fast-chat`（要快） |
| 语音识别 | `speech`（任何浏览器都能用，不再依赖 Edge） |
| 朗读 | `tts`（CosyVoice2，A/B 角色默认 anna / alex 两个音色） |
| 发音评测 | `pronunciation`（跟读、对话“照着说”时，对照原文打分） |

能力名和音色都能在 `.env` 里改。如果觉得 CosyVoice 读英语/日语不够地道，把 `TTS_PROVIDER` 改成 `edge`，朗读就换回微软 Edge 免费语音，其余照旧走网关。

**不填任何 Key 也能跑**：会进入演示模式，使用内置示例内容。不用网关时，也可以按 `.env.example` 填 DeepSeek 等 OpenAI 兼容服务。

## 功能

- **三种练习形式**
  - 话题问答：一问一答，问题自动朗读，适合面试、自我介绍、聊观点；开启“AI 追问”后，每题答完 AI 会根据你的回答再追问一句（可跳过，也可关闭）
  - 情景对话：选一个角色，对方台词自动朗读，轮到你时开口；可选“照着说”（练发音）或“自由说”（只给中文意思）
  - 短文：听全文 / 逐句听，逐句跟读并即时标出没读出来的词，然后回答理解题；“影子跟读”是原音播放的同时跟着说（建议戴耳机），会显示你比原音晚多少秒开口、用时是原音的几倍
  - 自由对话：不设剧本，AI 扮演一个角色（同事、面试官、店员……），根据你说的话一直聊下去，聊到自然结束或你点“结束对话”
  - 精听填空：听录音，把每句挖掉的 1–2 个关键词填上，专练听力细节；只算听力分
- **免手动对话**（练习右侧面板开关，问答 / 情景对话 / 自由对话可用）：AI 说完自动开麦，你停顿约 1.5 秒自动提交；说话时边说边出字（浏览器支持时）
- **难度自动调节**：首页根据最近成绩建议难度——同一难度最近平均 ≥85 分建议升一级、<60 分建议降一级；可勾选“按最近成绩自动调节难度”
- **薄弱项专练**：首页显示最近六维里最弱的一项，一键出一组针对它的题（听力→精听填空，发音→跟读短文，流利度→需要连续说一分钟的问题……），话题由系统挑
- **复习（生词本 + 错句本）**：学习笔记和报告里点 ☆ 收藏单词、句型；报告里被改正的句子自动进入错句本。“复习”页按遗忘曲线（SM-2）安排：单词交替“听音回忆”和“看中文说出来”，错句要开口说出正确句子（有网关时用发音评测判分）；四档自评“忘了 / 模糊 / 记得 / 很熟”决定下次什么时候再出现。左侧“复习”旁的数字是今天到期的张数
- **录音对比**：作答录音会随练习保存在服务器（`backend/data/audio/`），报告里每条都能在“我的录音”和“标准音”之间来回对比，以后从历史记录打开也能听
- **口音听辨**：听一句英语，从四个选项里猜是哪国口音，每轮 10 题，答完可以把四种口音对比着听
- **听力训练**：盲听模式（先隐藏原文，需要时点开）、0.8× / 1× / 1.2× 语速、中文翻译开关
- **听力口音**（首页或练习右侧面板选择，按语言分别记住）：
  - 英语：美洲（美国、加拿大、拉美口音）、欧洲（英国、爱尔兰、德国口音、法国口音）、亚洲（印度、新加坡、日本口音）、大洋洲（澳大利亚）
  - 日语：默认音色、东京标准音（微软）
  - 选了具体口音后，朗读改用微软 Edge 的地区音色（对话里 A/B 是该口音的一女一男）；“默认音色”仍走网关。标“模拟”的几种（日本、德国、法国、拉美口音）是让该国母语音色来读英文，听起来是真实的外国口音，但不是真人录音
- **学习笔记**：每个话题可以一键生成单词（音标/假名、词性、释义、例句）、语法点（讲解、例句、常见错误）、句型（用法、例句）总结，例句都能按所选口音播放。生成后自动保存，可以随时“重新生成”替换。练习页上方切到“学习笔记”、报告页底部、左侧“学习笔记”页面都能看到
- **作答**：点麦克风说，实时显示识别文字，可回放自己的录音、重录；也可以切换成文字输入
- **六维评分**：听力理解、发音清晰度、口语流利度、语法准确性、词汇运用、内容与表达，雷达图 + 逐条点评 + 修改后句子 + 更地道的说法（可播放）+ 值得记下的表达
- **历史记录**：所有练习存在本地 SQLite（`backend/data/langstudy.db`），可回看报告，显示得分变化

### 评分是怎么来的

分数不是全交给大模型拍脑袋，而是“实测 + 模型判断”混合：

| 维度 | 实测信号 | 模型判断 |
|---|---|---|
| 发音清晰度 | 有网关时：跟读/照读录音的发音评测分（85%）；没有时：与原文的吻合度、识别置信度（60%） | 识别结果中的错误 |
| 口语流利度 | 有效语速（去掉开头结尾的静音）、口头禅次数（50%） | 句子连贯程度 |
| 听力理解 | 每题重听次数、是否盲听（30%） | 回答是否切题、是否听懂 |
| 语法 / 词汇 / 内容 | — | 大模型批改 |

综合分在后端按权重计算。全部用文字作答时，发音和流利度显示“未评估”，不计入综合分。

**已知局限**：发音评测只在“有原文可对照”时进行（跟读、照着说）；自由回答的发音仍按识别结果估算。界面上“没读出来的词”的标注来自识别比对，日语里汉字/假名写法不同（如「一人」和「ひとり」）可能被误标。

```
│   │   ├── generate.py     生成材料（提示词 + 结果校验）

│   │   ├── mistakes.py     报告里的错句自动入库
│   │   ├── languages.py    语言与口音配置（新增语言、口音改这里）

│   │   ├── demo.py         演示模式内容

│   └── .env.example

    └── src/
        ├── App.vue         页面切换与全局状态
        ├── components/     AuthView / HomeView / PracticeView（五种模式各一个组件）/ ReportView / ReviewView（复习）/ AccentQuizView（口音听辨）/ HistoryView / NotesView / AdminView …

        └── diff.js         跟读比对
```

## 手动启动

```bash
# 后端
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # 填 Key
uvicorn app.main:app --reload --port 8000

# 前端（另开一个终端）
cd frontend
npm install
npm run dev
```

部署时可以 `cd frontend && npm run build`，后端会自动托管 `frontend/dist`，只需运行 uvicorn 一个进程。注意浏览器只在 `localhost` 或 HTTPS 下允许使用麦克风，所以给别人用要部署到 HTTPS 域名上；网关若开了租户 IP 白名单，要把服务器出口 IP 加进去。
